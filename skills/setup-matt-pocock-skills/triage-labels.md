# 分流標籤

這些 skills 以五個標準分流角色來溝通。這個檔案把這些角色對應到這個倉庫議題追蹤系統中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們追蹤系統中的標籤 | 意義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估這個議題 |
| `needs-info`               | `needs-info`         | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`    | 完整規格化，可交給 AFK 代理 |
| `ready-for-human`          | `ready-for-human`    | 需要人類實作 |
| `wontfix`                  | `wontfix`            | 不會處理 |

當 skill 提到某個角色時（例如「套用 AFK-ready 分流標籤」），就使用這張表中對應的標籤字串。

請編輯右側欄位，讓它符合你實際使用的詞彙。
