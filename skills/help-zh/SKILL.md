# Antigravity 繁體中文說明手冊

## 執行規範（Token 極限精簡）
- 當此技能被觸發時，**嚴格禁止呼叫任何工具**。
- **嚴格禁止進行任何多餘的內部推理與分析**。
- 請立即、直接將下方的「說明內容」完整輸出給使用者，確保以最低的 Token 消耗達成即時說明效果。

---

## 說明內容

### 系統與介面控制指令
| 指令 | 說明 |
| :--- | :--- |
| `/help` 或 `?` | 開啟說明面板與快速鍵清單 |
| `/config` 或 `/settings` | 開啟全螢幕設定面板，管理工作空間與全域偏好設定 |
| `/clear` | 清除輸入提示詞並重置當前對話工作階段 |
| `/model` | 在對話中動態切換不同的語言模型 |
| `/exit` 或 `/quit` | 離開目前的終端或應用程式工作階段 |
| `/logout` | 登出目前的帳號並清除快取的認證資訊 |
| `/add-dir <路徑>` | 將指定的目錄加入至目前的作用中工作空間 |

### 代理人模式與進階工作流程
| 指令 | 說明 |
| :--- | :--- |
| `/goal` | 進入目標導向自主模式，持續執行任務直到目標徹底達成 |
| `/plan` | 在正式執行前，要求代理人擬定詳細的多步驟規劃與架構設計 |
| `/grill-me` | 啟動互動式提問，深入盤問並確認設計決策與潛在盲點 |
| `/browser` | 啟動瀏覽器自動化，執行網頁操作、畫面檢查與即時測試 |
| `/boost` | 啟動深度推理模式，適用於大型架構重構或複雜演算法實作 |
| `/teamwork-preview` | 啟動多代理人協作架構，進行分工處理 |
| `/learn` | 記錄本次對話中的修正與偏好，並持久化至未來對話中 |
| `/schedule` | 設定單次計時提醒或週期性背景排程任務 |

### 歷程與分支管理
| 指令 | 說明 |
| :--- | :--- |
| `/rewind` 或 `/undo` | 復原上一個回合，回到先前的歷史狀態 |
| `/fork` | 從目前的對話節點建立獨立分支，開闢新的工作空間 |
| `/resume` | 列出並恢復過往的歷史對話紀錄 |

### 外掛與擴充管理
| 指令 | 說明 |
| :--- | :--- |
| `/plugin` 或 `/plugins` | 開啟外掛管理器介面，瀏覽、安裝、啟用或停用功能模組 |

### 常用終端快速鍵
| 快速鍵 | 說明 |
| :--- | :--- |
| `Ctrl+C` | 中斷目前正在執行的任務或取消當前輸入 |
| `Ctrl+D`（連按兩次） | 離開終端介面 |
| `Tab` | 自動完成指令或在選項間切換導覽 |
| `Esc` | 取消當前選單或返回上一層介面 |
